# Masked Parallel Analysis for Dimensionality Estimation

**Date:** 2026-03-18
**Context:** Derivation of a permutation-based rank estimator for symmetric similarity matrices, complementing the gap-based (kappa changepoint) method.

## 1. Setting and Notation

Let $S \in \mathbb{R}^{n \times n}$ be a symmetric positive semi-definite (PSD) similarity matrix with eigendecomposition

$$S = U \Lambda U^\top, \quad \Lambda = \mathrm{diag}(\lambda_1, \ldots, \lambda_n), \quad \lambda_1 \geq \cdots \geq \lambda_n \geq 0,$$

where $U = [u_1 \mid \cdots \mid u_n]$ is orthogonal. We assume $S$ may contain missing entries: each off-diagonal pair $(i,j)$ with $i < j$ is observed with probability $q \in (0,1]$.

**Masking model.** For a sampling fraction $p \in (0,1]$, define a Bernoulli mask $M(p) \in \{0,1\}^{n \times n}$ where each upper-triangular entry $M_{ij}(p) \sim \mathrm{Bernoulli}(p)$ independently for $i < j$, with $M_{ji} = M_{ij}$ and $M_{ii} = 1$. The masked estimator is

$$\widetilde{S}(p) = \frac{M(p)}{p} \circ S + \left(1 - \frac{M(p)}{p}\right) \circ D_S,$$

where $\circ$ denotes the Hadamard product and $D_S = \mathrm{diag}(S_{11}, \ldots, S_{nn})$. The diagonal is always preserved, and off-diagonal entries are scaled by $1/p$ to ensure unbiasedness:

$$\mathbb{E}[\widetilde{S}(p)] = S.$$

Define the perturbation $E(p) = \widetilde{S}(p) - S$. This is a symmetric random matrix with $E_{ii} = 0$ and, for $i \neq j$,

$$E_{ij}(p) = S_{ij}\left(\frac{M_{ij}(p)}{p} - 1\right),$$

so $\mathbb{E}[E_{ij}] = 0$ and $\mathrm{Var}(E_{ij}) = S_{ij}^2 \cdot \frac{1-p}{p}$.


## 2. The Dimensionality Question

We seek $k^*$: the number of eigenvalues representing signal (structured similarity) rather than noise (sampling variability, measurement error, or finite-sample artifacts). Two complementary formulations make this precise.

**B1 (Gap-based, Davis-Kahan).** Is the top-$k$ eigensubspace stable under perturbation? This requires the spectral gap $\lambda_k - \lambda_{k+1}$ to exceed $\|E\|_2$. The kappa changepoint method operationalizes B1.

**B2 (Noise-floor, parallel analysis).** Is $\lambda_k$ larger than what random structure produces under a suitable null? This is the question addressed here.

**Why both are needed.** Consider a matrix with eigenvalues decaying as $\lambda_k \propto k^{-\alpha}$ for some $\alpha > 0$. Consecutive gaps $\lambda_k - \lambda_{k+1} \approx \alpha k^{-\alpha - 1}$ shrink with $k$, so B1 terminates early: the subspace is unstable to perturbation even though many eigenvalues remain well above the noise floor. B2 continues to detect signal as long as $\lambda_k$ exceeds the null threshold, yielding a larger (and often more appropriate) rank estimate.


## 3. Null Model: Entry Permutation

**Null hypothesis $H_0$.** The eigenvalue structure of $S$ is no stronger than what arises from entries with the same marginal distribution but no pairwise structure.

**Construction.** Let $\pi$ be a uniformly random permutation of the index set $\{(i,j) : 1 \leq i < j \leq n\}$, which has $m = \binom{n}{2}$ elements. Define $S_\pi$ by:

- For each pair $(i,j)$ with $i < j$: $S_\pi[\pi(i,j)] = S[i,j]$,
- $S_\pi[j,i] = S_\pi[i,j]$ (symmetry),
- $S_\pi[i,i] = S[i,i]$ (diagonal preserved).

That is, we randomly reassign the $m$ off-diagonal values to the $m$ off-diagonal positions while keeping the matrix symmetric and preserving the diagonal.

**Properties preserved under permutation:**
- The multiset of off-diagonal entries (hence all marginal moments: mean, variance, skewness, etc.),
- The diagonal values $S_{ii}$,
- Symmetry.

**Properties destroyed:**
- All pairwise correlation structure between entries,
- Transitivity (if $S_{ij}$ and $S_{jk}$ are large, $S_{ik}$ need not be),
- Any latent factor structure $S \approx WW^\top$.

**Remark.** $S_\pi$ is symmetric but generically not PSD. This is expected and informative: a matrix whose off-diagonal entries are randomly arranged has no reason to be PSD, so its eigenvalues spread symmetrically around the mean. The presence of large positive eigenvalues in $S$ but not in $S_\pi$ is precisely the signal we detect.

**Claim.** Under $H_0$ (i.e., $S$ itself is a realization of the permutation model), the eigenvalue distributions of $S$ and $S_\pi$ are identically distributed.

*Proof sketch.* Under $H_0$, $S$ is generated by randomly placing the off-diagonal values, so $S$ and $S_\pi$ are equal in distribution. The eigenvalue map is a deterministic function of the matrix, so the eigenvalue distributions coincide. $\square$


## 4. Test Statistic and Procedure

Fix a grid of sampling fractions $\mathcal{P} = \{p_1, \ldots, p_P\}$ with $0 < p_1 < \cdots < p_P \leq 1$, and a maximum rank $K$ to test.

### 4.1. Observed eigenvalues (with bootstrap aggregation)

For each $p \in \mathcal{P}$:

1. Draw $B$ independent Bernoulli($p$) masks $M^{(1)}(p), \ldots, M^{(B)}(p)$.
2. For each $b = 1, \ldots, B$, form $\widetilde{S}^{(b)}(p)$ and compute its top-$K$ eigenvalues $\lambda_1(\widetilde{S}^{(b)}(p)) \geq \cdots \geq \lambda_K(\widetilde{S}^{(b)}(p))$.
3. Aggregate across bootstraps:

$$\lambda_k^{\mathrm{obs}}(p) = \mathrm{median}_{b=1}^{B}\; \lambda_k\!\left(\widetilde{S}^{(b)}(p)\right), \quad k = 1, \ldots, K.$$

The median is preferred over the mean for robustness to outlier eigenvalues caused by unlucky mask realizations.

### 4.2. Null eigenvalues (permutation replicates)

For each null replicate $j = 1, \ldots, J$:

1. Generate $S_\pi^{(j)}$ by entry permutation of $S$ (Section 3).
2. Draw one Bernoulli($p$) mask, form $\widetilde{S}_\pi^{(j)}(p)$, and compute its top-$K$ eigenvalues.
3. Record $\lambda_k^{\mathrm{null},j}(p)$ for $k = 1, \ldots, K$.

**Why one mask per null replicate (not $B$)?** Each null replicate $S_\pi^{(j)}$ is already an independent draw from $H_0$. The masking adds additional variability that is part of the null distribution we want to capture. Using a single mask per replicate (rather than $B$ masks with median aggregation) produces a null distribution that reflects the full variability of the masked estimator, making the test conservative relative to one that would also aggregate nulls. This asymmetry (aggregated observed vs. single-mask null) is intentional: it ensures the test has correct size.

**Proposition 1 (Validity of the single-mask null).** Let $T_k(S, M) = \lambda_k(\widetilde{S}(p))$ denote the $k$-th eigenvalue of the masked estimator. Under $H_0$, $T_k(S, M)$ and $T_k(S_\pi, M')$ are identically distributed when $M, M'$ are independent Bernoulli($p$) masks. Therefore, the quantiles of $\{T_k(S_\pi^{(j)}, M^{(j)})\}_{j=1}^J$ are valid critical values for the test statistic $\lambda_k^{\mathrm{obs}}(p)$ when $B = 1$. For $B > 1$ with median aggregation, the observed statistic has reduced variance, making the comparison against the wider null distribution conservative.

### 4.3. Null distribution and threshold

At each pair $(k, p)$, the null distribution is the empirical distribution

$$\mathcal{F}_k^{\mathrm{null}}(p) = \left\{\lambda_k^{\mathrm{null},j}(p) : j = 1, \ldots, J\right\}.$$

The critical value at level $\alpha$ is

$$\tau_k(p, \alpha) = Q_{1-\alpha}\!\left(\mathcal{F}_k^{\mathrm{null}}(p)\right),$$

where $Q_\gamma$ denotes the $\gamma$-quantile.

**Pointwise test.** Reject $H_0$ for dimension $k$ at sampling fraction $p$ if

$$\lambda_k^{\mathrm{obs}}(p) > \tau_k(p, \alpha).$$


## 5. Multiple Testing and Decision Rule

### 5.1. The family of tests

For each dimension $k$, we conduct $P$ pointwise tests (one per sampling fraction). Dimensions that represent true signal should be detectable at all sufficiently high masking rates: if $\lambda_k$ is above the noise floor, then even after removing a moderate fraction of entries, the $k$-th eigenvalue of $\widetilde{S}(p)$ should exceed the permutation null.

### 5.2. Intersection test across sampling fractions

Define a threshold $p_0 = \mathrm{median}(\mathcal{P})$, restricting attention to the upper half of the $p$-grid where masking is mild and signal dimensions should be clearly detectable.

**Decision rule.** Dimension $k$ is classified as signal if the pointwise test rejects $H_0$ at every $p \geq p_0$:

$$R_k = \bigcap_{p \in \mathcal{P},\; p \geq p_0} \left\{\lambda_k^{\mathrm{obs}}(p) > \tau_k(p, \alpha)\right\}.$$

This is an intersection-union test (IUT). Under $H_0$, if any single $p$ fails to reject, dimension $k$ is classified as noise.

### 5.3. Per-dimension p-value

The p-value for dimension $k$ under the intersection test is

$$p_k = \max_{p \in \mathcal{P},\; p \geq p_0} \left\{\frac{1 + \sum_{j=1}^{J} \mathbf{1}\!\left[\lambda_k^{\mathrm{null},j}(p) \geq \lambda_k^{\mathrm{obs}}(p)\right]}{1 + J}\right\}.$$

Taking the maximum over $p$ implements the intersection: $p_k$ is the worst-case p-value across all tested sampling fractions. The $+1$ in numerator and denominator is the standard correction for permutation p-values (Phipson and Smyth, 2010), ensuring $p_k > 0$ and exact validity.

### 5.4. Rank estimate

$$k^* = \max\{k : p_k < \alpha\},$$

with $k^* = 0$ if no dimension rejects.

**Proposition 2 (Type-I error control).** Under $H_0$, $\Pr(\text{reject } H_0 \text{ for dimension } k) \leq \alpha$ for each $k$.

*Proof.* For a fixed $k$, the intersection test rejects only if all pointwise tests reject. For any single $p \geq p_0$, the pointwise test has size at most $\alpha$ by construction of $\tau_k(p, \alpha)$ as the $(1-\alpha)$-quantile of the null. Since rejection requires passing all tests, $\Pr(R_k) \leq \min_{p \geq p_0} \Pr(\text{reject at } p) \leq \alpha$. Equivalently, $p_k = \max_p \hat{p}_k(p) \geq \hat{p}_k(p')$ for any fixed $p'$, and $\Pr(\hat{p}_k(p') < \alpha) \leq \alpha$ by validity of permutation tests. $\square$

**Remark on conservatism.** The IUT is conservative in general because it requires unanimous rejection. This is appropriate here: a dimension that is genuinely above the noise floor should survive at all $p \geq p_0$. Dimensions that pass at $p = 0.95$ but fail at $p = 0.55$ are marginally detectable and should not inflate $k^*$.


## 6. Connection to Davis-Kahan (B1)

### 6.1. The Davis-Kahan $\sin\Theta$ theorem

For any symmetric perturbation $\widetilde{S} = S + E$, let $\hat{U}_k$ denote the top-$k$ eigensubspace of $\widetilde{S}$ and $U_k$ the top-$k$ eigensubspace of $S$. If $\delta_k = \lambda_k - \lambda_{k+1} > 0$, then

$$\|\sin\Theta(\hat{U}_k, U_k)\|_2 \leq \frac{\|E\|_2}{\delta_k},$$

where $\Theta$ is the matrix of canonical angles.

### 6.2. Gap-based test (B1, kappa changepoint)

The gap condition $\delta_k > \|E\|_2$ guarantees $\|\sin\Theta\|_2 < 1$, i.e., the top-$k$ subspace is meaningfully stable. The kappa changepoint method estimates

$$\kappa_k = \frac{(1 - I_k(p)) \cdot p}{1 - p}$$

at high $p$, where $I_k(p)$ is a coherence measure. A large jump in $\kappa_k$ between consecutive dimensions indicates a spectral gap. The changepoint $k_{\mathrm{cut}}$ is where the largest such jump occurs.

This directly operationalizes B1: $k_{\mathrm{cut}}$ is the largest $k$ where the spectral gap is large relative to the perturbation.

### 6.3. Noise-floor test (B2, this method)

Parallel analysis asks a different question: is $\lambda_k$ itself above the noise floor? The noise floor is defined by the permutation null, which destroys all structure while preserving marginal statistics.

### 6.4. Complementarity

| Property | B1 (gap/kappa) | B2 (parallel analysis) |
|----------|-----------------|------------------------|
| Tests | Subspace stability | Eigenvalue significance |
| Requires | Large consecutive gaps $\delta_k$ | $\lambda_k$ above null |
| Conservative when | Gradual spectral decay | Sharp spectral gap with noise plateau |
| Result | Robust rank (worst-case perturbation) | Signal rank (eigenvalues above noise) |

For gradually decaying spectra (common in behavioral and neural similarity data), $\delta_k$ is small for all $k$ beyond the first few, so B1 terminates early. However, many eigenvalues may still be well above the permutation null, and B2 detects these.

**Combined interval.** Define $k_{B1} = k_{\mathrm{cut}}$ (kappa changepoint) and $k_{B2} = k^*$ (parallel analysis). The interval $[k_{B1}, k_{B2}]$ brackets the effective dimensionality:

- $k_{B1}$ is the number of dimensions with robust spectral gaps (survives worst-case perturbation of size $\|E\|_2$).
- $k_{B2}$ is the number of dimensions with eigenvalues above chance level.

For well-separated spectra (block-structured data), $k_{B1} \approx k_{B2}$. For continuous spectra (e.g., THINGS behavioral), $k_{B1} \ll k_{B2}$, and the interval width reflects the ambiguity inherent in rank selection for such data.


## 7. Computational Considerations

### 7.1. Cost breakdown

| Operation | Cost per instance | Instances | Total |
|-----------|-------------------|-----------|-------|
| Entry permutation of $S$ | $O(m)$ where $m = \binom{n}{2}$ | $J$ | $O(Jn^2)$ |
| Bernoulli mask + rescaling | $O(n^2)$ | $JP + BP$ | $O((J+B)Pn^2)$ |
| Top-$K$ eigendecomposition | $O(n^2 K)$ via `eigh` subset, or $O(nK \cdot n_{\mathrm{Lanczos}})$ via `eigsh` | $JP + BP$ | $O((J+B)P n^2 K)$ |

The dominant cost is the $(J + B) \cdot P$ eigendecompositions.

### 7.2. Practical parameters and scaling

For $n = 1854$ (THINGS behavioral), $K = 120$, $J = 100$, $B = 50$, $P = 25$:

- Null eigendecompositions: $J \cdot P = 2500$
- Observed eigendecompositions: $B \cdot P = 1250$
- Total: 3750 eigendecompositions of $1854 \times 1854$ matrices

Each `eigh` call on a $1854 \times 1854$ matrix takes approximately 0.1-0.3s. Total wall time (serial): ~6-19 minutes. With parallelization across replicates (embarrassingly parallel in $j$ and $b$), this reduces to minutes on a multi-core machine.

### 7.3. Parallelization strategy

The outer loop over null replicates $j = 1, \ldots, J$ and bootstrap replicates $b = 1, \ldots, B$ is embarrassingly parallel. For each $(j, p)$ or $(b, p)$ pair, the computation is independent. Use `joblib.Parallel` with $n_{\mathrm{jobs}}$ workers, dispatching tasks as (replicate_index, $p$-grid) pairs.

Within each replicate, the $P$ masking rates can be processed sequentially (using nested masks for variance reduction) or in parallel. Sequential processing with nested masks is preferred: draw one set of uniform random variables $\{U_{ij}\}$ per replicate and threshold at each $p$ to obtain nested masks $M(p_1) \subseteq M(p_2) \subseteq \cdots$ when $p_1 \leq p_2$. This reduces variance across the $p$-grid without additional random number generation.

### 7.4. Memory

The null eigenvalue array has shape $(K, P, J)$, requiring $K \cdot P \cdot J \cdot 8$ bytes. For $K = 120$, $P = 25$, $J = 100$: approximately 2.3 MB. The observed eigenvalue array has shape $(K, P, B)$: approximately 1.2 MB. Memory is not a bottleneck.
