# The Permutation Coherence Test (PCT): A Practical Explainer

**Date:** 2026-03-19

## The problem: how many dimensions does a similarity matrix have?

Suppose you have measured how similar 1,854 objects are to each other, producing an 1854 x 1854 similarity matrix S. You want to factorize this matrix into a small number of latent dimensions, so that each object is described by a compact vector. But how many dimensions should you use?

This is a rank selection problem. Use too few dimensions and you miss real structure. Use too many and you fit noise, wasting compute and reducing interpretability. You need a principled way to decide.

## Why existing approaches fall short

**Cross-validation on held-out entries.** Fit a low-rank model (such as symmetric NMF) at each candidate rank, hold out some matrix entries, and see which rank best predicts the held-out values. This works, but it is expensive and the answer depends on which model you chose. A rank that is optimal for NMF might differ from one optimal for eigendecomposition.

**Eigenvalue-based parallel analysis (Horn, 1965).** Compare the eigenvalues of your matrix against those of a "null" matrix (typically generated by permuting entries or sampling from a random distribution). Dimensions whose eigenvalues exceed the null threshold are retained. This is the classical method. It works well for fully observed matrices, but it *breaks* when data is partially observed. The reason: eigenvalue magnitudes scale with the observation rate. At 30% observation, both real eigenvalues and null eigenvalues are small, and the threshold becomes unreliable. In experiments on synthetic rank-10 matrices, the eigenvalue test gives k* = 20 at 10% observation and k* = 8 at 20% observation. The estimate is non-monotone (it goes *down* when you add data), which is clearly wrong.

**Kappa changepoint.** Instead of looking at eigenvalue sizes, look at how *stable* each eigenvector is when you randomly hide some entries. Eigenvectors that encode real structure survive this masking; those that encode noise do not. The "kappa" statistic quantifies this stability, and the changepoint is where stability drops sharply. This works correctly for partially observed data and gives monotone estimates. The limitation: it looks for the single biggest drop in stability. For matrices with gradually decaying structure (no sharp gap between signal and noise), it finds the first major transition and stops. It can underestimate the rank by missing weaker dimensions that still carry meaningful structure.

**Activation counting.** Test each eigenvector against a theoretical null threshold (the coherence expected from a random Gaussian direction, approximately 1/n). Any eigenvector exceeding this threshold is called "active." The problem: for large matrices, 1/n is tiny. For THINGS (n = 1854), the threshold is about 0.0005, which almost everything exceeds. This gives k* = 97 when independent evidence suggests the answer is closer to 25. The null is too weak.

## The PCT solution

PCT keeps the stability-under-masking framework (which handles partial observation correctly) but replaces the weak theoretical null with an empirical null constructed by permutation. The core question it asks: "Does dimension k of my matrix carry more structure than you would see in a matrix with the same entries shuffled randomly?"

### The building block: projection coherence (Iproj)

Before describing the test, we need to understand what Iproj measures.

Take your similarity matrix S and compute its eigendecomposition. The k-th eigenvector u_k describes a "direction" in the space of objects. Now randomly hide a fraction of the entries (Bernoulli masking at rate p, meaning each off-diagonal entry is kept independently with probability p). Compute the eigenvectors of this masked matrix. Measure how well the k-th eigenvector of the original matrix is captured by the top-k eigensubspace of the masked matrix.

Formally, Iproj_k(p) = || P_k(S_masked) * u_k(S) ||^2, where P_k projects onto the top-k eigensubspace.

This quantity is between 0 and 1:
- Iproj = 1 means the eigenvector survived masking perfectly.
- Iproj = 0 means the eigenvector was completely lost.

The critical property of Iproj is that it measures *angles* between subspaces, not eigenvalue magnitudes. Scaling S by a constant, or observing only a fraction of its entries, does not bias this angle. This is what makes the coherence framework valid for partial data where eigenvalue methods fail.

### The test, step by step

**Step 1: Measure the coherence of the real data.**

Compute the eigendecomposition of S (specifically, of S with missing entries set to zero). This gives reference eigenvectors. Then apply B random Bernoulli masks at each of several masking rates p, compute the eigenvectors of each masked version, and measure Iproj. Take the median across the B masks to get a stable estimate: Iproj_k^obs(p).

**Step 2: Build a null by permuting the matrix.**

Take the observed entries of S and shuffle them randomly among the observed positions. This produces a matrix S_pi that has the same values, the same sparsity pattern, the same marginal distribution, but no pairwise structure. If objects 7 and 42 were highly similar in the original, that similarity value now sits at a random position. The "meaning" is destroyed while the statistical properties of the entries are preserved.

**Step 3: Measure the coherence of the permuted matrix.**

This is the subtle part. Compute the eigenvectors of S_pi, then apply random masks and measure how well S_pi's eigenvectors survive masking. Critically, you compare S_pi against *itself*, not against the real data. You are asking: "How much coherence does a structureless matrix produce?"

Repeat for J permuted matrices (typically J = 100) to build a null distribution.

**Step 4: Compare.**

For each dimension k and masking rate p, you now have:
- Iproj_k^obs(p): the coherence of the real data.
- {Iproj_k^null,j(p) : j = 1,...,J}: the null distribution from permuted matrices.

Compute a p-value: what fraction of null replicates produced coherence as high or higher than the observed? If the observed coherence significantly exceeds the null, dimension k carries real structure.

### The intersection test: combining across masking rates

PCT does not test at a single masking rate. It tests across a grid of rates p, and requires significance at all rates above the median of the grid. The per-dimension p-value is defined as the *worst* (highest) p-value across these rates:

    p_k = max over {p >= median(p_grid)} of [(1 + count(null >= obs)) / (1 + J)]

This is conservative by design. A dimension must be consistently detectable, not just marginally significant at one rate, to be called signal.

The estimated rank k* is the largest dimension that passes this test at significance level alpha (typically 0.05).

### Why the null comparison works

For signal dimensions: the eigenvectors encode real relationships (e.g., "all animals cluster together"). This structure is present in every random subsample of the entries, so the eigenvectors survive masking well. The permuted matrix has no such relationships, so its eigenvectors are fragile. Signal Iproj greatly exceeds null Iproj.

For noise dimensions: the eigenvectors are artifacts of the particular sample. They do not survive masking any better than the eigenvectors of a permuted matrix. Signal Iproj is roughly equal to null Iproj.

The permutation null is calibrated to the specific matrix: its size, sparsity, value distribution, and diagonal. The only thing it removes is the structure you are testing for.

## Monotonicity: more data means more dimensions detected

A rank estimator should never find *fewer* dimensions when given more data. PCT satisfies this.

With more observations (higher observation rate):
- Signal eigenvectors are better estimated, so they survive masking better, and Iproj increases for signal dimensions.
- The null eigenvectors do not benefit from more observations (there is no structure to recover), so null Iproj stays roughly flat.
- The gap between signal and null widens, and more dimensions cross the threshold.

This was validated on synthetic rank-10 matrices (n = 200, Dirichlet factors, averaged over 5 seeds):

| Observation rate | 10% | 20% | 30% | 50% | 70% | 100% |
|:----------------|----:|----:|----:|----:|-----:|-----:|
| PCT k* (mean)   | 0.8 | 2.4 | 3.0 | 7.6 | 9.8  | 10.0 |
| Eigenvalue test  | 20  |  8  | 11  | 14  | 10   | 10   |

PCT is perfectly monotone and converges to the true rank. The eigenvalue test is non-monotone and wildly overestimates at low observation rates.

## How PCT relates to the kappa changepoint

These two methods answer different questions about the same data:

| | Kappa changepoint | PCT |
|:--|:--|:--|
| **Question** | Which dimensions have spectral gaps large enough to survive worst-case perturbation? | Which dimensions carry structure above what random entry assignment produces? |
| **Interpretation** | Robust rank (conservative) | Signal rank (inferential) |
| **Strength** | Finds the clear boundary between strong and weak dimensions | Tests each dimension against a proper null hypothesis |
| **Weakness** | Underestimates when eigenvalues decay gradually (no big gap) | Requires J eigendecompositions of the full matrix (computationally heavier) |

For THINGS behavioral data (1854 objects, triplet-derived similarity):
- Kappa gives k* = 6 (5% data) to k* = 26 (100% data).
- PCT gives k* = 4 (5% data) to k* = 25 (100% data).

These are reassuringly close. Both are much lower than the 91-111 dimensions estimated by the broken activation method, and lower than the 10-52 dimensions used by VICE (a variational embedding model). Yet SRF at these coherence-estimated ranks achieves higher validation accuracy than VICE at every data level, suggesting that the lower ranks correctly capture the useful structure without overfitting.

In practice, reporting both gives a bracket: [k_kappa, k_PCT] captures the range of reasonable ranks.

## Important caveats

**The first eigenvalue often fails the test.** For non-negative similarity matrices, the Perron-Frobenius eigenvalue (capturing overall mean similarity) is large for both real and permuted matrices. The permuted matrix also has a dominant first eigenvector driven by the non-negative entry distribution, so the null is strong at k = 1. This is correct behavior: the mean similarity level is not latent structure worth modeling.

**Resolution depends on J.** With J = 100 permutation replicates, the smallest achievable p-value is approximately 0.01 (specifically, 1/101). For finer resolution or stricter significance thresholds, increase J.

**The intersection test is deliberately conservative.** Requiring significance at all masking rates above the median prevents dimensions that are only marginally detectable at one rate from inflating the rank. If a dimension is genuinely structured, it should be detectable across a range of conditions.

**Computational cost.** For each of the J null replicates, you must compute a full eigendecomposition of the n x n matrix, then apply P masking rates and compute P more eigendecompositions. For THINGS (n = 1854) with J = 100, B = 30, and P = 15, this totals about 1,950 eigendecompositions. On a single core, each takes roughly 2 seconds, giving about 65 minutes. With 100+ cores via joblib, this drops to about 5 minutes. The computation is embarrassingly parallel since each replicate is independent.

## Summary

PCT answers the question "how many dimensions does my similarity matrix have?" by comparing the stability of eigenvectors under random masking to the stability you would expect from a matrix with no pairwise structure. It works for partially observed matrices (where eigenvalue methods fail), gives monotone estimates (more data never reduces the rank), and provides proper p-values for each dimension. It is somewhat conservative by design, which is appropriate for selecting a model rank where overfitting is the main risk.
