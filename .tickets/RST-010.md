## RST-010: Update Hydra configs for new output paths

### CRITICAL: NO FUNCTIONAL CHANGES
This ticket updates config paths only.

### Goal
Update Hydra configs to write project outputs to central location.

### Files to Modify
- `configs/mode/production.yaml`

### Implementation
```yaml
# configs/mode/production.yaml
# @package _global_
hydra:
  run:
    dir: ${project_root}/outputs/projects/${experiment_name}/${task}/${now:%Y-%m-%d_%H-%M-%S}
  sweep:
    dir: ${project_root}/outputs/projects/${experiment_name}/${task}/${now:%Y-%m-%d_%H-%M-%S}
    subdir: ${hydra.job.override_dirname}
```

### Files to Check for Hardcoded Paths
Search for and update any hardcoded output paths:
```bash
grep -r "experiments/.*/outputs" --include="*.py" --include="*.yaml"
grep -r "/outputs/" configs/experiment/
```

Known files to check:
- `configs/experiment/ppi.yaml` - Check results_dir references
