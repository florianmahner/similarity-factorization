## RST-012: Update pyproject.toml package paths

### CRITICAL: NO FUNCTIONAL CHANGES
This ticket updates package configuration only.

### Goal
Update pyproject.toml to include projects/ instead of experiments/.

### Files to Modify
- `pyproject.toml`

### Implementation
```toml
[tool.poetry]
packages = [
    {include = "*", from = "src"},
    {include = "projects"}  # was: experiments
]
```

### Testing
- [ ] `poetry install` succeeds
- [ ] `poetry run python -c "import projects"`
- [ ] `poetry run python -c "from projects.ppi.models import get_predictor"`
- [ ] `poetry run pytest tests/test_structure.py -v`

### Acceptance Criteria
- [ ] Poetry recognizes projects package
- [ ] All imports still work
- [ ] No import errors on `poetry install`
