## RST-009: Create central outputs/ and move project outputs

### CRITICAL: NO FUNCTIONAL CHANGES
This ticket moves output files only.

### Goal
Create central outputs/ directory, move existing project outputs there.

### Commands to Execute
```bash
# Create structure
mkdir -p outputs/projects

# Move existing outputs (for each project that has them)
mkdir -p outputs/projects/ppi
mv projects/ppi/outputs/* outputs/projects/ppi/ 2>/dev/null || true

mkdir -p outputs/projects/word_association
mv projects/word_association/outputs/* outputs/projects/word_association/ 2>/dev/null || true

mkdir -p outputs/projects/simulation
mv projects/simulation/outputs/* outputs/projects/simulation/ 2>/dev/null || true

mkdir -p outputs/projects/things_behavior
mv projects/things_behavior/outputs/* outputs/projects/things_behavior/ 2>/dev/null || true

mkdir -p outputs/projects/bounds
mv projects/bounds/outputs/* outputs/projects/bounds/ 2>/dev/null || true

mkdir -p outputs/projects/rsa_comparison
mv projects/rsa_comparison/outputs/* outputs/projects/rsa_comparison/ 2>/dev/null || true

mkdir -p outputs/projects/graph_clustering
mv projects/graph_clustering/outputs/* outputs/projects/graph_clustering/ 2>/dev/null || true

mkdir -p outputs/projects/embedding_generation
mv projects/embedding_generation/outputs/* outputs/projects/embedding_generation/ 2>/dev/null || true

# Remove empty output dirs
rmdir projects/*/outputs/ 2>/dev/null || true
```

### Files to Modify
- `.gitignore` - Add `outputs/` if not present

### Testing
- [ ] `ls outputs/projects/` shows project subdirs
- [ ] No outputs/ folders inside projects/

### Acceptance Criteria
- [ ] All project outputs in outputs/projects/
