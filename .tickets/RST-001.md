## RST-001: Create backup and safety branch

### CRITICAL: NO FUNCTIONAL CHANGES
This ticket creates safety infrastructure only.

### Goal
Create a complete backup and git branch before any restructuring.

### Commands to Execute
```bash
# 1. Create backup directory
mkdir -p ../similarity-factorization-backup

# 2. Backup data and outputs
cp -r data/ ../similarity-factorization-backup/data/
cp -r experiments/*/outputs/ ../similarity-factorization-backup/experiment_outputs/ 2>/dev/null || true
cp -r development/*/outputs/ ../similarity-factorization-backup/development_outputs/ 2>/dev/null || true

# 3. Create and switch to refactor branch
git checkout -b refactor/repo-structure
git push -u origin refactor/repo-structure
```

### Testing
- [ ] Backup directory exists with data/
- [ ] Git branch created and pushed
- [ ] Can switch back to master: `git checkout master && git checkout refactor/repo-structure`

### Acceptance Criteria
