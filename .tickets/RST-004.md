## RST-004: Update sandbox configs for local outputs

### CRITICAL: NO FUNCTIONAL CHANGES
This ticket updates Hydra config paths only.

### Goal
Ensure sandbox experiments write outputs locally (self-contained).

### Files to Modify
- `configs/mode/development.yaml` - Rename to sandbox.yaml, update paths
- `configs/base.yaml` - Update default mode

### Implementation
Rename and update config:
```yaml
# configs/mode/sandbox.yaml (was development.yaml)
# @package _global_
hydra:
  run:
    dir: ./outputs/${now:%Y-%m-%d}/${now:%H-%M-%S}
  sweep:
    dir: ./outputs/${now:%Y-%m-%d}/${now:%H-%M-%S}
    subdir: tmp/${hydra.job.num}
```

Update `configs/base.yaml` default:
```yaml
defaults:
  - mode: sandbox  # was: development
```

### Testing
- [ ] Config loads: `poetry run python -c "from omegaconf import OmegaConf; OmegaConf.load('configs/mode/sandbox.yaml')"`
- [ ] `poetry run pytest tests/test_structure.py -v`

### Acceptance Criteria
- [ ] `configs/mode/sandbox.yaml` exists
- [ ] `configs/mode/development.yaml` removed or deprecated
- [ ] Base config references sandbox mode
